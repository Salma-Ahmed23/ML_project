# 🧠 Classification Analysis on UCI Credit Card Dataset

This project focuses on predicting whether a credit card client will default on the next month's payment using machine learning techniques.

## 📌 Dataset
UCI Credit Card Default Dataset

## 🔍 Project Workflow
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Handling class imbalance
- Feature scaling
- Train/Test split with stratification

## 🤖 Models Used
- Logistic Regression
- Support Vector Classifier (SVC)

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

## 🛠 Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
